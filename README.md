# Titanic Survival Predictor 🚢

A machine learning web application that predicts whether a passenger would have survived the Titanic disaster, built with Flask and Random Forest Classifier.

# Demo




## Features 
- **Web Interface**: Three interactive pages for prediction flow
- **Passenger Details Form**: Collects critical information (class, age, fare, etc.)
- **Survival Prediction**: Displays result with probability percentage
- **Machine Learning Model**: Random Forest classifier trained on Titanic dataset
- **Responsive Design**: Clean UI with gradient backgrounds and modern styling
